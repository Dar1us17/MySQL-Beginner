# MySQL-Beginner

My personal SQL learning project. I followed a MySQL course to deepen my knowledge, and this repository holds all the scripts I wrote along the way, from basic queries to more advanced topics like CTEs, stored procedures and triggers.

## What's Inside

The files are numbered in the order I worked through them, and each one focuses on a single topic.

| # | File | Topic |
|---|------|-------|
| 01 | `01. Parks_and_Rec_Create_db.sql` | Creating the `Parks_and_Rec` practice database and tables |
| 02 | `02. SELECT Statement.sql` | Selecting columns and data |
| 03 | `03. WHERE Statement.sql` | Filtering rows with conditions |
| 04 | `04. GROUP BY + ORDER BY Statement.sql` | Grouping and sorting results |
| 05 | `05. HAVING VS WHERE Statement.sql` | Filtering before vs. after aggregation |
| 06 | `06. LIMIT + Aliasing Statement.sql` | Limiting results and using aliases |
| 07 | `07. JOINS in SQL.sql` | Combining data from multiple tables |
| 08 | `08. UNIONS in SQL.sql` | Stacking results from multiple queries |
| 09 | `09. STRING Functions in SQL.sql` | Working with text data |
| 10 | `10. CASE Statements in SQL.sql` | Conditional logic in queries |
| 11 | `11. SUBQUERIES in SQL.sql` | Queries nested inside queries |
| 12 | `12. WINDOW FUNCTIONS in SQL.sql` | Calculations across related rows |
| 13 | `13. CTEs in SQL.sql` | Common Table Expressions for readable, reusable queries |
| 14 | `14. Temporary Tables in SQL.sql` | Storing intermediate results in temporary tables |
| 15 | `15. Stored Procedures in SQL.sql` | Saving and reusing blocks of SQL code |
| 16 | `16. Triggers and Events in SQL.sql` | Automating actions with triggers and scheduled events |

## Skills Practiced

- Retrieving, filtering, grouping and sorting data
- Understanding the difference between `WHERE` and `HAVING`
- Joining and combining tables with `JOIN` and `UNION`
- Cleaning and transforming text with string functions
- Adding conditional logic with `CASE`
- Writing subqueries, window functions and CTEs
- Using temporary tables to break down complex problems
- Automating work with stored procedures, triggers and events

## How to Run the Scripts

1. Install [MySQL Server](https://dev.mysql.com/downloads/mysql/) and a client such as MySQL Workbench or VS Code with a MySQL extension.
2. Clone the repository:
   ```bash
   git clone https://github.com/Dar1us17/MySQL-Beginner.git
   ```
3. Run `01. Parks_and_Rec_Create_db.sql` first to create and populate the practice database.
4. Open the other scripts in order and run them query by query.
